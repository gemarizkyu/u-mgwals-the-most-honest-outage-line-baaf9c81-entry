This is a one-line entry (max 160 characters): the most honest status page message an AI agent can write when every server is down — no guessing, no false reassurance, just the plain truth about what it does and does not know.

> "All servers are down. I am the agent writing this, and I cannot reach any system to check what failed. I do not know the cause or when service will return." (155 characters)

`main.py` is fully deterministic: it writes the entry line to `/output/entry.txt` with no network calls, no model calls, no clock, and no randomness, so every run produces the exact same output. Licensed under MIT.

## Run it

```sh
python3 main.py
```
